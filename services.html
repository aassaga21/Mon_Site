Services & Spécialités

Ce que je peux concrètement apporter à votre organisation

Spécialisée en infrastructure, cloud, automatisation et cybersécurité, j'interviens sur des missions ciblées avec une approche structurée : analyse → conception → déploiement → supervision → documentation.

Domaines d'expertise

Mes 4 domaines de spécialité

🖧

Infrastructure & Réseaux

Conception, déploiement et administration d'infrastructures réseau fiables, segmentées et documentées.

  • Conception d'architecture réseau — topologie, segmentation VLAN, sous-réseaux, routage.
  • Administration de serveurs — Windows Server, Linux (Ubuntu/Debian), gestion des rôles et services.
  • Virtualisation — déploiement et gestion de VMs avec VMware, Proxmox ou Hyper-V.
  • Haute disponibilité — clustering, Live Migration, reprise sur panne, Veeam / Acronis.
  • Téléphonie IP — installation et configuration de solutions 3CX.
  • Documentation technique — schémas, procédures, guides d'exploitation exploitables.
☁️

Cloud Computing

Déploiement et gestion d'infrastructures cloud sur Azure et AWS, avec une approche sécurisée et économique.

  • Azure — VNet, Virtual Machines, Azure Files SMB, Azure Bastion, Security Groups.
  • AWS — EC2, RDS MySQL, Security Groups, déploiement d'applications web dynamiques.
  • Architecture cloud sécurisée — segmentation, accès restreints, gestion des identités.
  • Infrastructure as Code (IaC) — provisionnement reproductible avec Terraform sur Azure / AWS.
  • Migration vers le cloud — analyse des besoins, planification et déploiement progressif.
  • Optimisation des coûts — dimensionnement adapté, nettoyage des ressources inutilisées.
⚙️

Automatisation & DevOps

Réduction des tâches répétitives, déploiement automatisé et infrastructure reproductible à grande échelle.

  • Terraform — provisionnement automatique de VMs, réseaux et services cloud.
  • Ansible — configuration automatique des systèmes, installation de services (Apache, MariaDB…).
  • Proxmox + IaC — création automatique de machines virtuelles sur hyperviseur.
  • n8n — automatisation de workflows métier, intégrations entre outils.
  • Scripts Bash / PowerShell — automatisation de tâches d'administration système.
  • Git & GitHub — versionnement du code d'infrastructure, collaboration en équipe.
🛡️

Cybersécurité & Réseaux sécurisés

Protection des infrastructures, des données et des accès avec une approche "sécurité by design".

  • Firewall & filtrage — configuration de règles OPNsense, pfSense, Fortinet (NAT, IPS, filtrage applicatif).
  • VPN — mise en place de tunnels sécurisés client-to-site et site-to-site (IPsec, OpenVPN).
  • Segmentation réseau — isolation des zones (LAN, DMZ, WAN), réduction de la surface d'attaque.
  • Durcissement des systèmes — bonnes pratiques de configuration, réduction des expositions.
  • Supervision sécurité — surveillance des logs, alertes, tableaux de bord Grafana / Zabbix.
  • Audit & documentation sécurité — état des lieux, recommandations et plan de remédiation.
